carry is now one click in Claude Desktop

7 Nov 2026 · by @heyvamz

Until now, using carry inside Claude Desktop meant opening a config file and pasting JSON into it. That is fine for developers and a wall for everyone else. carry 0.4.1 removes it.

Claude Desktop: download, double-click

Every release now comes with carry.mcpb, a Claude Desktop extension. Download it, double-click, click Install. Then ask Claude "connect carry to my Google Drive" and "share this chat with Riya". You still need Node installed.

Claude Code: a plugin

The carry repo is now its own plugin marketplace. Two commands install the connector and the /carry skill together:

$ claude plugin marketplace add vamzzisme/carry $ claude plugin install carry@carry

Listed in the MCP Registry

carry is in the official MCP Registry as io.github.vamzzisme/carry, so apps that search the registry can find it.

Safer by default

Every carry tool now tells your AI app whether it only reads (listing chats, checking your inbox) or sends something (sharing, returning). Apps use that to ask you before anything leaves your laptop.

Full list of changes in the changelog. Setting up from scratch? Copy the setup prompt and let your AI do it.
