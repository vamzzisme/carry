01How it works

Three commands. No copy paste.

Type /carry inside Claude Code or Codex and it runs these for you.

1

Pick a chat

carry list shows your chats by name, not by long IDs. Rename any of them. Nothing is shared until you pick it.

2

Share it

carry share strips API keys and tokens, uploads one small file to your Drive and Google emails the link to your friends.

3

Keep going anywhere

carry open <link> on any laptop loads the full chat into Claude Code or Codex, on whichever account is signed in there.

03Privacy

Your Drive. Not our servers.

carry runs on your laptop. There is no carry server and no account with us. Chats go from your computer to your Google Drive and nowhere else.

Only its own files

carry asks Google for the narrowest Drive permission: it can see and edit only the files it created. The rest of your Drive stays off limits.

Secrets stripped first

API keys, tokens, private keys and KEY=value lines are replaced with [REDACTED] before anything leaves your laptop.

You choose who sees it

Share with named friends by email, or make a link. Nothing is shared by default, and you can delete the file from Drive at any time.

Open source

Built on txcript, the open chat converter by SkillSync. Read the code, run it yourself, change it.

04Install

Two minutes, once per laptop.

Needs macOS, Node 22.15 or newer, and the free txcript CLI.

# get carry $ git clone https://github.com/vamzzisme/carry && cd carry $ npm install && npm link # sign in to Google Drive in your browser $ carry setup --web --as yourname

Get txcript for your Mac from its releases page and put it in ~/.local/bin.

# add /carry to Claude Code (or ~/.codex/skills for Codex) $ cp -r skills/carry ~/.claude/skills/

Already use Google Drive for desktop, Dropbox or iCloud? Run carry setup instead and share one synced folder with your group.

05FAQ

Questions, answered.

Does my chat go to a VXMZ server?

No. carry has no server. It reads chats from your laptop, uploads them to your own Google Drive, and downloads them on the other side. We never see them.

Can my friend continue on their own account?

Yes, that is the point. The chat opens in whichever Claude Code or Codex account is signed in on their laptop, so their tokens are used, not yours.

Can I move a Claude Code chat into Codex?

Yes. carry open <link> --to codex converts the full conversation into a Codex session. For chat apps like ChatGPT, carry gives you a short handoff file to attach instead.

What gets redacted?

Common secret shapes: OpenAI, Anthropic and Sarvam keys, GitHub tokens, AWS and Google keys, Slack tokens, JWTs, Bearer tokens, private keys and lines like API_KEY=value. It is pattern based, so do not share chats full of secrets you care about.

Why does Google say the app isn't verified?

carry is new and still in Google's testing stage. Click Advanced, then continue. It only asks for access to files carry itself creates.

Do I need the Google Drive app?

No. Web mode signs in through your browser. If you already use Drive for desktop, Dropbox or iCloud, you can point carry at a synced folder instead.

Can carry read my claude.ai or ChatGPT web chats?

Not yet. Those live on their servers. Inside those apps, ask the AI to write a handoff and attach it on the other side. A browser extension is on the roadmap.

What does it cost?

Nothing. carry is free and open source. If it saves you a few hours, a coffee keeps the studio going.
