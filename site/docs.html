carry docs

Everything carry does, with the exact commands. carry runs on your computer and shares through your own Google Drive or a synced folder. There is no carry account.

Quick start

The fastest way: let your AI do it. Copy the setup prompt and paste it into Claude Code, Codex or Cursor. It checks Node, installs carry and connects your Drive, asking you before each step.

Open it in:

ClaudeChatGPTCursor

The prompt points at carry-si.vercel.app/setup.md, a page written for AI assistants. Read it first if you like.

Or by hand, with Node 22.15 or newer:

$ npm install -g @heyvamz/carry $ carry install-skill # adds /carry to Claude Code and Codex $ carry setup --web --as yourname # sign in to Google Drive in your browser

Then open a new terminal: setup also turns on Tab completion, so carry open + Tab fills in your chats and friends.

How to use

carry moves a chat or a project two ways: between tools and accounts on your own laptop, or to a friend's laptop.

On your laptop: another tool or account

Out of tokens in Claude Code? Keep going in Codex, the Codex app, the Claude app, or Claude Code signed in to another account. No pairing and no friend needed.

$ carry list # find the chat $ carry share fix-the-login-bug # pack it into your Drive $ carry open fix-the-login-bug --to codex # or claude_app

The chat opens with its full history, as that tool's own session. To use another account, sign in to it in the tool first, then open. See Open and continue for every --to.

To a friend: another laptop

Borrow a friend's tokens, or hand the work over. Pair once, then send by name.

# You (after pairing once with Riya) $ carry share fix-the-login-bug --to riya # Riya $ carry inbox $ carry open 1 --to claude_app $ carry return fix-the-login-bug # sends her progress back to you

It travels encrypted through your own Google Drive and runs on Riya's account. Pairing, links without pairing and whole projects are below in Share with friends.

Install

Works on macOS, Windows and Linux. You need Node 22.15 or newer, and git if you share whole projects.

1. Node and git

$ brew install node git

No Homebrew? Get the installer from nodejs.org. macOS asks to install git the first time you use it.

# in PowerShell > winget install OpenJS.NodeJS.LTS > winget install Git.Git

Then close PowerShell and open a new window so it finds node and git.

# Ubuntu or Debian $ curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - $ sudo apt-get install -y nodejs git

Other distros: any Node 22.15 or newer from your package manager or nodejs.org.

2. carry

$ npm install -g @heyvamz/carry $ carry doctor # versions, txcript, and how sharing is set up
$ sudo npm install -g @heyvamz/carry $ carry doctor # versions, txcript, and how sharing is set up

carry uses txcript to convert chats between tools. It is downloaded and checksum-checked for your system on install, or the first time carry needs it.

3. The /carry command

$ carry install-skill

Adds the /carry skill to Claude Code, Codex and ~/.agents. Type /carry in a chat and the AI runs the commands below for you.

Connect Google Drive

carry needs somewhere to put shared chats. Pick one, once per laptop.

Web mode (default)

$ carry setup --web --as yourname

Opens Google sign-in in your browser. You sign in and click Allow. carry asks only for drive.file: it can see and edit the files it creates, nothing else in your Drive. The name after --as is what friends see. Setup also turns on Tab completion for chat and friend names in zsh, bash and PowerShell; open a new terminal to use it. Add --with a@gmail.com,b@gmail.com to share with the same people by default.

If Google shows "Google hasn't verified this app", click Advanced, then continue.

Synced folder mode

$ carry setup # finds Google Drive for desktop $ carry setup ~/Dropbox/carry # or any synced folder

Already use Google Drive for desktop, Dropbox or iCloud? Point carry at a folder and share that folder with your group. No Google sign-in.

Your chats

$ carry list fix-the-login-bug claude_code 2h ago stacked-reveal-effect codex 3d ago $ carry name stacked-reveal-effect landing page animation

carry reads Claude Code chats from ~/.claude/projects and Codex chats from ~/.codex/sessions. Names come from the first real prompt, with secrets removed. Rename any chat with carry name.

Share with friends

Pair once

# You $ carry friend add riya@gmail.com # prints a pairing code: send it to Riya on any chat app # Riya $ carry friend add <your code> # prints her code back # You $ carry friend add <Riya's code> # done, both ways

The codes carry a key that encrypts everything you send each other (AES-256-GCM). carry friends lists who you're paired with; carry friend remove <name> unpairs.

Send, open, send back

# You $ carry share fix-the-login-bug --to riya # Riya $ carry inbox # 1. fix-the-login-bug chat from you NEW $ carry open 1 --to codex # or --to claude_code $ carry return fix-the-login-bug # You $ carry inbox # 1. fix-the-login-bug UPDATED by Riya (+18 messages) $ carry open 1 --to claude_code

The chat opens on Riya's own account, so her tokens are used. If you also kept working on your copy, carry opens her version next to yours and overwrites nothing.

Send back automatically

Share with --auto-return and Riya's carry sends the chat back after she works on it, when carry sync runs. carry install-hook runs it after every Claude Code session.

Share without pairing

$ carry share fix-the-login-bug --with riya@gmail.com # Google emails Riya a link $ carry share fix-the-login-bug --link # anyone with the link # Riya $ carry open <drive link> --to codex

A private (email) link opens in Riya's browser; she clicks Download and carry picks the file up from Downloads. carry packs lists what you've shared, and carry sync re-uploads shared chats that changed.

Share a whole project

$ carry projects # your repos, with chats and Claude memory notes $ carry projects my-app # its chats, plus related chats started elsewhere $ carry share --project my-app --add <related chat> --to riya

A project pack holds the newest chats started in the repo (5 by default, --chats N), any you --add, minus any you --skip (or --related for all related chats), Claude Code's memory notes, CLAUDE.md and AGENTS.md, and a handoff. The code itself goes through git.

# Riya, after cloning the repo $ carry open 1 --to claude_code --dir ./my-app $ carry return --project my-app # her new chats and memory notes come back

Claude Code gets your memory notes and a handoff note where it reads them at the start of a session. Codex gets a .carry/ folder and a pointer line in AGENTS.md. Nothing of Riya's is overwritten: a note changed on both sides is kept as <note>.from-<friend>.md.

Open and continue

carry open <name | file.carry | Drive link | inbox number> --to <target>

--toWhat happens
claude_codeLoaded as a real Claude Code session, full history, and opened in your terminal. No claude command? carry runs it with npx.
claude_appSame session, opened in the Claude desktop app's Code tab. No terminal tool needed.
codexConverted into a Codex session and opened with codex, the copy inside ChatGPT for Mac, or npx.
codex_appSame session, opened in the Codex app. No terminal tool needed.
opencode · cursor · piConverted by txcript. Less tested.
chatFor a plain chat in claude.ai, ChatGPT or the Claude app: copies a prompt and shows the handoff file to attach.
herePrints the handoff and history, for an AI that is already reading your terminal.

Chat apps

claude.ai, ChatGPT and the Claude app keep chats on their servers, so carry can't read their history. Ask the AI to write a handoff (goal, what was done, decisions, next steps), save it, and share it as a summary:

$ carry note "auth bug in login" --handoff summary.md

With the connector installed, just say "share this conversation with Riya" and the AI writes and sends the summary itself.

Use it inside AI apps

carry runs as an MCP connector. Add it once, then ask in plain words. It always runs the latest version. You need Node installed, nothing else.

Claude Desktop: one click

Download carry.mcpb

Double-click the file (or drag it into Claude Desktop) and click Install.

Claude Code: plugin

$ claude plugin marketplace add vamzzisme/carry $ claude plugin install carry@carry

Installs the connector and the /carry skill together.

Updates

Run carry update. carry checks npm once a day and tells you when a new version is out; turn that off with CARRY_NO_UPDATE_CHECK=1. The connector (@heyvamz/carry@latest) updates itself. See the changelog.

Privacy and security

  • carry runs on your computer. Chats go from your computer to your Google Drive (or synced folder) and nowhere else. No carry server, no telemetry.
  • Google access is drive.file only. Your sign-in token stays in ~/.carry/google.json, readable only by you. Revoke it at myaccount.google.com/permissions.
  • Before anything leaves your laptop, carry replaces common secret shapes with [REDACTED]: OpenAI, Anthropic and Sarvam keys, GitHub tokens, AWS and Google keys, Slack tokens, JWTs, Bearer tokens, private keys and KEY=value lines. It is pattern based, so don't share chats full of secrets you care about.
  • Friend shares are encrypted with AES-256-GCM using a key that lives only in your pairing codes.
  • Shared files stay in your Drive until you delete them. Settings live in ~/.carry/.

Troubleshooting

carry: command not found

npm's global bin folder isn't on your PATH. Run npm prefix -g, add its bin folder to PATH and open a new terminal. On Windows, open a new PowerShell window.

Permission denied on npm install -g (Linux)

Use sudo npm install -g @heyvamz/carry, or install Node with nvm so global installs don't need root.

Couldn't get txcript

Run carry doctor again once you're online. Opening with --to chat or --to here doesn't need txcript.

Sign-in times out or the browser doesn't open

carry prints the sign-in link; open it yourself. It waits 5 minutes.

My Codex chats don't show up

carry reads ~/.codex/sessions (or $CODEX_HOME/sessions). Chats from the Antigravity app and from claude.ai or ChatGPT on the web can't be read; share a summary instead.

The connector doesn't show up

Restart the app after editing its config. Check node -v is 22.15 or newer. On Windows the config must use "command": "cmd" with "/c", "npx".

Opening a project changed nothing

carry never overwrites existing files; it prints "kept your existing …" for those. Merge by hand if you want the incoming version.

FAQ

Can I move a Claude Code chat into Codex?

Yes. carry open <ref> --to codex converts the full conversation into a Codex session.

Do I need the Google Drive app?

No. Web mode signs in through your browser. If you already use Drive for desktop, Dropbox or iCloud, you can use a synced folder instead.

Can carry read my claude.ai or ChatGPT web chats?

Not yet. Those live on their servers. Share a summary instead.

Does it work on Windows and Linux?

Yes. Every release is tested on macOS, Windows and Linux.

What does it cost?

Nothing. carry is free and open source (Apache-2.0).
